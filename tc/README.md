# Tropical cyclones

This folder holds the **Climatology & Trends — 5° grid** tool (`trends/tctrend.html`) and its
pre-generated data, basemap and build/audit scripts.

The single-storm **TC Track & Wind-Field Explorer** (IBTrACS event viewer) is no longer
hosted here. It lives on its own site, **[tcviewer.org](https://tcviewer.org/)**
(repo `drchavas/tcviewer`). The landing page and `tctrend.html` both link there.
